## 📄 Descrição

Este projeto é um programa simples desenvolvido em **PHP** que exibe a mensagem "Hello World" na tela. Seu objetivo é demonstrar de forma prática o uso do PHP em conjunto com um servidor local, como o **XAMPP**, e também servir como exercício de versionamento com o git e GitHub.
